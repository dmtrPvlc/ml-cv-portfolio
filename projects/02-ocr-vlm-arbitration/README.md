# Проект 2: Интеллектуальная обработка документов (OCR + VLM)

## Описание задачи

Автоматизировать извлечение структурированных данных (текст, таблицы) из сложных PDF-документов с высокой точностью, минимизируя ошибки классических OCR-систем и обеспечивая безопасность данных.

## Решение

Создан гибридный конвейер: классические быстрые OCR-движки используются для массовой обработки, а легковесная локальная Vision-Language Model (VLM) подключается точечно для семантического арбитража спорных или нечетких участков текста.

## Результаты и метрики

- Надежность: стабильный конвейер конвертации PDF в Excel с извлечением табличных данных.
- Безопасность: использование локальной VLM (Qwen2.5-VL) исключает утечку конфиденциальных данных во внешние API, что критично для промышленных и корпоративных задач.
- Качество: значительное снижение процента ошибок (hallucinations) за счет алгоритмического арбитража спорных участков текста.
- Автоматизация: полное исключение ручного переноса данных из документов в таблицы.

## Технологический стек

- Python
- Transformers (Qwen2.5-VL)
- Surya OCR
- Tesseract
- pypdfium2 (работа с PDF)
- OpenCV
- OpenPyXL (формирование Excel)
- JSON, CSV
- Git (локальный репозиторий)
