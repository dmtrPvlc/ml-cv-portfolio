# Проект 3: Видеоаналитика и трекинг объектов

## Описание задачи

Обеспечить автоматическое обнаружение, трекинг и прогнозирование траектории перемещающихся объектов на видеопотоке в реальном времени (включая летающие и наземные объекты).

## Решение

Модульная система, объединяющая высокоскоростной детектор объектов с кастомной логикой трекинга и модулем прогнозирования, с постоянным мониторингом утилизации аппаратных ресурсов для предотвращения OOM (Out of Memory).

## Результаты и метрики

- Производительность: стабильный инференс на уровне 72–143 FPS (в зависимости от разрешения входного потока и выбранной модели).
- Функциональность: успешная реализация прогнозирования траектории для движущихся объектов.
- Интеграция: система успешно встроена в замкнутый цикл, позволяя экспортировать логи и кадры с ошибками для последующего дообучения моделей (Active Learning).
- Мониторинг: контроль GPU/VRAM/CPU/RAM в реальном времени для предотвращения сбоев.

## Технологический стек

- Python
- OpenCV
- Ultralytics (YOLO)
- Custom Tracking Logic
- psutil, GPUtil (мониторинг GPU/VRAM/CPU/RAM)
- YAML (конфигурации)
- Git (локальный репозиторий)
